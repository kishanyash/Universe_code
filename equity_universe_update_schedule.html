Equity Universe — Field Update Schedule & Documentation

Database: Supabase → public.equity_universe
Primary Key: (company_id, isin_code)
Unique Constraints: isin_code, nse_code
Last Updated: 2026-04-21
Universe Size: ~895 stocks

1. Schedule Overview

Frequency When Source(s) Est. Runtime Field Count Purpose
One-Time On stock addition Manual / Initial seed — ~7 Identifiers that never change
Daily Every day 6:30 AM IST Yahoo Finance (yfinance API) ~20 min ~48 Prices, volume, returns, derived valuations
Weekly Every Monday 7:30 AM IST Screener.in (HTTP + BeautifulSoup) ~50 min ~83 TTM financials, ratios, balance sheet, quarterly results, sectors, FY actuals
Biweekly 1st & 15th 8:30 AM IST Trendlyne + GoIndiaStocks (Selenium) ~3–4 hours ~65 Analyst targets, forward estimates (FY26E–FY28E)
Quarterly Jan/Apr/Jul/Oct 1st, 9:30 AM IST Screener.in (same as Weekly) ~50 min ~83 Post-earnings safety-net refresh

IMPORTANT: Each schedule scrapes only what is unique to that frequency — no duplication across schedules. When multiple sources provide the same field (e.g., current_price from Yahoo + Screener), the last writer wins.

2. One-Time / Static Fields

These are set once when a stock is added to the universe and rarely (if ever) change. Manual update only if a corporate action occurs (e.g., ticker change, demerger).

6. Quarterly Fields

PURPOSE: The quarterly run scrapes the exact same fields as Weekly. It acts as a post-earnings-season safety net to ensure new numbers are captured even if a weekly run had errors during earning dates.

10. Operational Notes

Master Lookup (Sample Grouping)

There are over 160 columns, mostly driven by:

  • Yahoo: Price, Volume, MCap, 52W High/Low, Daily Returns (1m-12m)
  • Screener: P&L (Sales, EBITDA, PAT) up to TTM, Margins, Balance Sheet (Debt, Cash, Net Block, CWIP)
  • Analyst estimates: Targets, Forward FY26-FY28 values

Write Priority Order

When multiple scrapers write the same field, the last writer wins:

Daily (6:30 AM) → Weekly (7:30 AM) → Biweekly (8:30 AM) → Quarterly (9:30 AM)

CAUTION: Never update isin_code or company_id — these are immutable identifiers.
